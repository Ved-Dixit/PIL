This is a basic PIL Generator using Pretrained GPT-2 as a base model to generate the document.
The model has been set to generate PILs in the scenarios which you will have to select from the drop down bar.
Once the Drop Down bar is open, the selection of your preferred category is present.
The Database consists of various files from the Indian Penal Code (formerly used), The Environment Protection Act, The Human Rights act and much more.
As the category is selected the model will dive deep into the articles and the clauses it needs to look upon.
The entry of appeals, court proceedings, and the summary assists the model into knowing the needful information on which the PIl needs to be generated
The temperature is set to a low of 0.6 to avoid any possible misgeneration and minimize any possiblity of Hallucination
